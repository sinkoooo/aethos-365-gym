# Abstract: AI-Driven UI Navigation Assistant for Telecommunication Management Systems in Constrained Environments

**Abstract**— Modern telecommunication network management systems, such as the Samsung Unified System Manager (USM), exhibit immense architectural and operational complexity, rendering operator navigation and device configuration challenging for non-expert users. Compounding this challenge are stringent deployment constraints inherent to telecommunications operator environments, specifically mandatory air-gapped networks and reliance on conventional CPU-only server infrastructures. This paper proposes a novel, resource-efficient Artificial Intelligence (AI) Navigation Assistant architecture designed exclusively for such heavily constrained enterprise web applications. Instead of employing resource-intensive visual processing or continuous Document Object Model (DOM) analysis by a Large Language Model (LLM), the proposed framework utilizes a highly optimized hybrid approach. It introduces a human-guided UI mapping mechanism via a browser extension to extract structural navigation data, establishing a localized, vector-based UI Element Database. During operation, operator intents expressed in natural language are processed using a highly quantized local LLM (e.g., 4-bit architectures) operating efficiently on standard CPUs. The LLM translates user intents into semantic queries, retrieving deterministic UI locators via Retrieval-Augmented Generation (RAG). A lightweight client-side extension then visually guides the operator using a multi-tiered, resilient locator fallback array, effectively decoupling UI traversal from computationally expensive real-time inference. The proposed architecture guarantees strict data sovereignty, resilience to dynamic UI framework updates, and sub-second operational latency without relying on external cloud APIs or GPU acceleration, thereby establishing a robust paradigm for AI integration in secure enterprise systems.

**Index Terms**— Telecommunications Management, Artificial Intelligence, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), DOM Parsing, CPU Optimization, Edge Computing, User Interface (UI) Navigation.
